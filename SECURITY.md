# Security reports

Do not include secrets or sensitive deployment data in a public issue. Use
GitHub's private vulnerability reporting when enabled, or request a private
contact channel from the maintainer without posting exploit details publicly.

SimWeave 0.1 is an MVP for trusted, single-host use. See the tracked threat model
for boundaries and the API operations guide before exposing the service to a
network. No physical robot actuation or safety guarantees are provided.
